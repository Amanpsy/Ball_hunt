Box Hunt Game (Vanilla JavaScript)
About the Project

This is a small grid-based game built using HTML, CSS, and vanilla JavaScript.
The goal of this task was to implement basic game behavior using plain JavaScript, focusing on logic, timing, and DOM updates.

What Works

Start

Starts the game and places a ball in a random box on the grid.

The ball keeps moving to different random positions at a fixed interval.

Pause

Stops the game by clearing the interval.

The ball stays at its current position when paused.
